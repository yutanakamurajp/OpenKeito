OpenKeito in the browser

OpenKeito is an open simulator of electromagnetic transients (EMT) in power systems. This page runs its solver in your browser as WebAssembly: choose an example or edit the model, and run it. Nothing is sent to a server.

The model is checked as you type. Ctrl+Enter (⌘+Enter) runs it. Try a mistake: misspell a field, make a resistance negative, or name a node that does not exist.

    The model was edited after these results were computed. Run it again to update them.

    About the diagram Drawn from the model as you type; positions are not stored. Press a component to select it in the model, or put the cursor into a component in the model to find it here. A bus is a bar, with one line for the three phases; a link such as “← pwm” leads to the control blocks and back. Errors and warnings are marked with ! at what they are about. After a run, the diagram shows what the model records at the time of the cursor of the waveforms, and whether a switch, a diode or a fault conducts there; a press on a component also switches its columns on in the waveforms.

    Run a model to see its waveforms.

    A frequency scan computes the impedances seen from the nodes and buses that the model lists under frequency_scan, with all sources set to zero. Choose an example that has one (the fault behind a transformer, the line energization) and press “Frequency scan”.

    Run a model to see its summary: status, warnings, solver counts and computing time.
